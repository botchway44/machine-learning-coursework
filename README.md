## Included work

### Loan Prediction Data Analysis

An academic activity completed with Tao Yuan using a loan-approval dataset with 614 records.

The notebook demonstrates:

- Dataset inspection with pandas
- Missing-value handling using mode and median
- Categorical feature encoding
- Class-imbalance analysis
- Correlation analysis
- Histograms, count plots, and box plots
- Outlier and distribution analysis
- Stratified train/test splitting
- Comparison of 80/20 and 67/33 splits
